# Nomify — Landing Page

Marketing landing page for **Nomify**, a B2B/SaaS-Ready platform that automates administrative processes between companies and their employees.

## Stack

- **Framework:** TanStack Start (React, SSR)
- **Styling:** Tailwind CSS v4
- **Forms:** Netlify Forms (newsletter signup)
- **Deployment:** Netlify

## Key Sections

1. **Navigation** — sticky top bar with links and CTA
2. **Hero** — dark gradient with headline, stats, and dual CTAs
3. **Trust bar** — company logos strip
4. **Features** — 5 product modules as colored cards
5. **How it works** — 3-step onboarding process
6. **Testimonials** — 3 customer quotes with featured center card
7. **CTA Band** — full-width gradient with conversion focus
8. **Footer** — contact info, links, and newsletter signup

## Local Development

```bash
npm install
netlify dev --port 8889
```

Visit `http://localhost:8889`
